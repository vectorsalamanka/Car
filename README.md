# 🚗 ماشین بازی

یک وب‌سایت زیبا برای جستجو و فیلتر کردن ماشین‌های مختلف

## ✨ ویژگی‌ها

- 🔍 **جستجو** - جستجو بر اساس نام ماشین و برند
- 🎯 **فیلتر** - فیلتر بر اساس برند، نوع و قیمت
- 📱 **ریسپانسیو** - طراحی متناسب برای تمامی دستگاه‌ها
- 🎨 **طراحی زیبا** - رابط کاربری مدرن و جذاب
- ⚡ **سریع** - بدون نیاز به سرور

## 📂 ساختار فایل‌ها

```
├── index.html    # صفحه اصلی
├── style.css     # استایل‌ها
├── script.js     # عملکرد
└── data.json     # داده‌های ماشین‌ها
```

## 🌐 مشاهده وب‌سایت

https://vectorsalamanka.github.io/car/

## 🛠️ تغییرات

اگر می‌خواهید ماشین‌های بیشتری اضافه کنید:
1. فایل `data.json` را باز کنید
2. یک ماشین جدید به آرایه اضافه کنید
3. تغییرات را commit کنید
